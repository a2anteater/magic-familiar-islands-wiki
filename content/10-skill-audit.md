# Skill 精简审计

> 状态：待讨论。57 个 Skill 先完整保留，本页只记录审计问题，不在本轮直接删除。

## 审计原则

一个 Skill 进入 MVP，至少应满足以下条件：

1. 已有三个或以上真实使用场景；
2. 能被事件 Judge 清楚理解和比较；
3. 与相邻 Skill 有稳定且易解释的边界；
4. 至少有一个可用来源，且不会绕过职业独占或世界知识；
5. 删除它会损失一种无法由相邻 Skill 合理表达的玩法。

## 审计输出格式

逐个 Skill 讨论后，只允许四种结论：`MVP 保留`、`合并`、`延期`、`删除`。每次结论需要同步更新 Skill Catalog、动物来源、基础魔法、职业前置、物品来源和事件模板引用，避免只改显示表。
