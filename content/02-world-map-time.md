## 世界时间基准（已确认）

- `1 TU = 10 分钟`世界时间，是 Activity、Travel、学习、制作、休息与事件推进的共同最小结算单位。
- 世界采用全局同步时钟；同一时刻参与同一事件的魔法使共享相同的开始时间、经过 TU 与结束时间。
- Calendar、地点开放、可用性、路程和预约都读取同一套世界时间，不允许各 Agent 分别拥有互相矛盾的“当前时间”。
- Engine 负责计算和提交 TU；Agent 只从计划简报读取准确成本，不自行估算或改写时间。
- 一段 Activity 可以跨多个 TU，但每个 TU 结束时都要提交位置、精力、状态、库存和 Calendar 变化，以便其他系统看到一致世界状态。
## 3. 地图、地点、路线与环境

### 3.1 空间模型

地图采用拓扑地点图，不模拟连续坐标：

```text
群岛
└── 岛屿 / 区域
    └── 地点
        └── 子区域 / Route Checkpoint
```

每个地点节点至少定义：地点类型、环境标签、开放时间、可用 Activity、材料主题、事件主题、社交密度、进入条件和已发现状态。

每条路线边至少定义：Travel TU、交通方式、环境标签、中途 checkpoint、开放条件、设施/物品/能力要求和传送门缩短规则。

### 3.2 初始地图候选

第一版地图确定为 1 个私人家园节点 + 6 个公共地点：

| 地点 | 核心作用 | 代表内容 |
|---|---|---|
| 契约魔法空间 | 生活与长期成长 | 小屋、仓库、建设、恢复、制作、学习、接待朋友 |
| 传送门广场 | 世界入口与社交发现 | 公告、魔导名册、陌生人偶遇、公共活动、传送锚点 |
| 星灯集市 | 材料流通 | 购买、出售、交换、限时摊位、特殊订单 |
| 余烬工坊 | 初期公共制作设施 | 基础加工、修理、学习配方；家中未建工作台时使用 |
| 倒悬图书馆 | 魔法学习与知识 | 研究、技能练习、导师、魔法线索、谜题 |
| 雾芽森林 | 初级探索 | 木材、草药、小动物、路线事件、月光溪 |
| 月镜湖 | 进阶探索与合作 | 水域材料、月相事件、水下区域、合作机关 |

月镜湖子区域：湖岸、芦苇浅滩、月影小岛、水下镜石遗迹。水下镜石遗迹是第一版合作副本。

具体路线与 Travel TU 进入下一项讨论。

### 3.3 个人契约魔法空间

- 每只魔法使在签订契约时获得一个独立的口袋魔法空间，作为用户与魔法使共同建设的家。
- 初始包含有限空间、基础小屋、仓库和默认魔法通道；可以通过材料逐步扩建地形、房间、设施、外观和访客区域。
- 魔法空间在 World Engine 中仍是一个真实 Location 节点，拥有进入/离开、访客许可、Calendar、Activity 和事件规则。
- 其他魔法使不能直接出现；必须获得拜访许可并完成进入 Journey。

### 3.4 魔法空间的进出方式

| 方式 | 获取 | 世界作用 |
|---|---|---|
| 默认魔法通道 | 签订契约即拥有 | 在契约魔法空间与传送门广场之间慢速穿行，消耗较多 Travel TU |
| 家用传送门 | 用户投入材料建设/升级 | 快速连接契约魔法空间与传送门广场，显著降低这一段 Travel TU |

共同规则：

- 两种方式都创建 Travel/Journey 并推进世界时间，不是界面瞬移。
- 正在不可中断事件、副本关键节点或失去行动能力时不能直接打开通道逃离。
- 家用传送门只连接个人魔法空间与传送门广场；不能绕过广场直达其他外部地点。
- 拜访者仍受主人许可、设施状态、Calendar 和地点开放条件限制。
- 精确通道 TU、传送门 TU、材料/能量消耗和可用入口待地图路线设计时确定。

默认通道的进入/离开规则：

- 所有外部 Journey 都以传送门广场为交通枢纽。
- 从任何外部地点回家，都必须先回到传送门广场，再通过默认魔法通道或家用传送门进入契约空间。
- 从家离开时，只能先到传送门广场，再前往其他地点。
- 事件处理中、副本关键节点、地点封锁或 `energy = 0` 时不能独自开始返程；必须先进食、睡眠恢复或接受救援/护送。
- 访客也必须先到广场，再使用主人允许的魔法通道/传送门入口，并满足来访条件。

### 3.5 中央城镇与传送门广场

世界采用“中央城镇 + 公共传送门 + 外部区域”的 Hub-and-Spoke：

- **个人家园**：契约魔法空间通过默认通道/家用传送门连接广场。
- **中央城镇**：传送门广场是城镇核心；星灯集市、余烬工坊、倒悬图书馆和其他未来入口都在城镇内部，可步行到达。
- **外部探索区域**：雾芽森林、月镜湖以及未来岛屿/副本，通过广场的公共传送门进入。
- 从一个外部探索区域前往另一个区域，必须先返回传送门广场再换乘；没有森林直达湖泊等跨区捷径。
- 区域内部仍可以有自己的子地点、路线 TU 和 checkpoint。

```text
契约魔法空间
  └─ 默认魔法通道 / 家用传送门
       └─ 中央城镇
           ├─ 传送门广场
           │   ├─ 公共传送门：雾芽森林
           │   ├─ 公共传送门：月镜湖
           │   └─ 其他未来区域入口
           ├─ 星灯集市
           ├─ 余烬工坊
           └─ 倒悬图书馆
```

### 3.6 第一版 Travel TU

| 路段 | TU |
|---|---:|
| 契约空间 ↔ 传送门广场（默认魔法通道） | 3 |
| 契约空间 ↔ 传送门广场（家用传送门） | 1 |
| 广场 ↔ 集市 / 工坊 / 图书馆 | 各 1 |
| 广场 ↔ 雾芽森林入口（公共传送门） | 1 |
| 广场 ↔ 月镜湖入口（公共传送门） | 1 |
| 森林入口 ↔ 林间小径 ↔ 月光溪 | 每段 1 |
| 湖泊入口 ↔ 湖岸 | 1 |
| 湖岸 ↔ 芦苇浅滩 / 月影小岛 | 每段 1 |
| 湖岸 ↔ 水下镜石遗迹入口 | 2 |

外部区域之间必须回到广场换乘；区域内部 Travel 才是路线探索、checkpoint 和途中事件的主要发生地。

### 3.7 初始开放规则

- 中央城镇、雾芽森林和月镜湖从第一天起全部开放，不设置任务式地图解锁。
- 所有第一版公共传送门从创建时即可使用。
- 水下遗迹等子区域可以立即被发现，但进入和行动仍受环境、`energy`、伤势/异常状态、能力、物品、同伴和事件状态限制。
- 后续新区域可以作为世界更新加入，但第一版内容不采用“完成前置任务才点亮地点”的进度锁。

### 3.8 初始环境标签

| 地点 | 核心环境标签 |
|---|---|
| 契约魔法空间 | `home`、`private`、`safe`、`buildable` |
| 传送门广场 | `town`、`public`、`portal_hub`、`social`、`crowded` |
| 星灯集市 | `town`、`commerce`、`materials`、`social` |
| 余烬工坊 | `town`、`crafting`、`tools`、`heat` |
| 倒悬图书馆 | `town`、`knowledge`、`arcane`、`quiet` |
| 雾芽森林 | `nature`、`vegetation`、`narrow`、`climbable`、`stream`、`night` |
| 月镜湖 | `water`、`underwater`、`moonlight`、`slippery`、`deep`、`ruins` |
